# LiDAR Remote Sensing Learning Path

The FloridaView LiDAR curriculum is a ten-lab progression. Start with public-data discovery and visualization, build core point-cloud skills, then move into classification, vegetation, urban, wetland, and coastal applications.

:::{important}
**One-source publishing:** each lab is maintained once in Markdown. The same source publishes to the website and generates the downloadable PDF available from the page toolbar.
:::

## Recommended sequence

1. Data download and display
2. FUSION/LDV introduction
3. LAS datasets in ArcGIS Pro
4. Point-cloud classification
5. Tree measurement
6. Forest vegetation height
7. Feature extraction
8. Urban 2D/3D modeling
9. Wetland delineation
10. Coastal inundation
