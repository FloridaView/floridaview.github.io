# Accessibility

FloridaView is designed so educational content remains usable across devices and assistive technologies. The publishing workflow includes semantic headings, descriptive link text, keyboard-friendly navigation inherited from the site theme, and text alternatives for instructional figures.

## Current scope

The LiDAR laboratories rely on screenshots of graphical desktop software. FloridaView provides text alternatives and surrounding procedural instructions for these figures, but some tasks remain visually dependent because the underlying desktop applications themselves are graphical interfaces.

If you encounter an accessibility barrier in FloridaView material, please report the page and the step where the issue occurs so the source can be improved.
