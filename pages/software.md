# Software & Access

The LiDAR learning path uses three primary desktop applications. Keep this page current rather than copying long vendor installation instructions into every lab.

| Software | Used in | Platform | Access | Documentation |
|---|---|---|---|---|
| ArcGIS Pro | Labs 3, 4, 6–10 | Windows | FAU SSO / licensed local installation | [ArcGIS Pro documentation](https://pro.arcgis.com/) |
| FUSION/LDV | Labs 2, 5 | Windows | Free distribution | [FUSION/LDV](https://forsys.sefs.uw.edu/fusion/fusionlatest.html) |
| Quick Terrain Reader | Lab 1 | Windows | Free download | [Applied Imagery downloads](https://appliedimagery.com/download/) |
| FAU Apporto | Alternative ArcGIS access | Browser | FAU students | [FAU Apporto](https://fau.apporto.com/) |
