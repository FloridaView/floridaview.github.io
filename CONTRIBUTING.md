# Contributing to FloridaView

Preserve the approved scientific meaning, FloridaView identity, and single Markdown source for each lab. Make small reviewable changes, retain descriptive image alternatives, and keep large datasets outside this repository.

Install the pinned tools as described in `README.md`, then run `npm run build` and `python3 scripts/check_external_links.py`. Review the generated web pages and PDFs. Commit to a review branch, open a PR to `main`, and wait for the latest **Validate FloridaView / build** check. Curriculum changes require PI review. Merge only after the build and visual review gates pass.

See `MAINTAINER_GUIDE.md` for deployment, DNS, and rollback details.
